# D'Lusha's Website

Website for **D'Lusha's** — a coffee & fresh-food cart on the promenade in
Ganei Tikva. *"It's All Good."*

## Contents
- **`index.html`** — the website prototype. Self-contained (no build step);
  open it in any browser.
- **`DESIGN-NOTES.md`** — the language strategy (English/Hebrew/both), what was
  borrowed from the reference sites, the imagined ordering flow, and the list of
  real content to swap in before launch.

## Quick start
Open `index.html` in a browser. Use the **EN / עב** toggle (top right) to switch
between English and Hebrew (the page flips to right-to-left for Hebrew).

## Status
Early prototype built on the brand identity system. Photography, real Google
reviews, hours/map, and links are placeholdered — see `DESIGN-NOTES.md`.
