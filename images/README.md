# Images

Drop brand photography and the logo here.

## Logo (wired into the site)

The site's nav and footer automatically use:

    images/logo-badge.png

Upload the **cup-and-leaf badge** (the circular mark, ideally **no wordmark text**,
on a **transparent background**) with exactly that filename. The moment it exists,
it replaces the temporary drawn placeholder in the header and footer — no code
change needed.

- Recommended: square PNG, transparent background, at least 256×256px.
- If the background isn't transparent, that's fine — the nav clips it to a circle.
